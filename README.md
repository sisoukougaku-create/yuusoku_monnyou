# Neo有職文様ジェネレーター

平安時代から続く「有職文様（ゆうそくもんよう）」を、ブラウザ上で
**アレンジ・組み合わせ・新規生成**できるアプリです。

## 使い方

`index.html` をブラウザで開くだけで動きます（インストール不要）。

| タブ | できること |
| --- | --- |
| アレンジ | 亀甲花菱・立涌・七宝・青海波などの伝統文様を選び、大きさ・回転・花びらの数・配色を調整 |
| 組み合わせ | 「地紋（骨組み）」×「文様（花）」×「重ねる地紋」を自由に組み合わせ |
| 新規生成 | シード（数字）から新しい花の文様・配色・構成を生成。同じシードなら同じ結果を再現 |

- **派生案を作る**：今のデザインを少しずつ変えた候補を6つ表示（クリックで採用）
- **SVG / PNG で保存**：SVG は拡大しても劣化しないベクター形式、PNG は 2000px の画像

## ファイル構成

```
index.html        画面の骨組み
css/style.css     見た目
js/random.js      シード付き乱数（同じシード→同じ結果）
js/palettes.js    配色（襲の色目 風）
js/lattices.js    地紋（亀甲・菱・襷・立涌・七宝・青海波・鱗・散らし）
js/motifs.js      文様（花菱・唐花・七曜・四つ菱・桔梗・霰）と描画
js/render.js      設計データ → SVG 画像
js/generator.js   プリセット・新規生成・派生案
js/app.js         画面操作とデータをつなぐ
```

## しくみ（ひとことで）

文様を「骨組み（地紋）」と「花（文様）」に分け、花は
「同じ花びらを中心のまわりに n 枚まわして並べたもの」という設計図で表しています。
設計図の数字（花びらの枚数・形・長さ・幅）を変えることで、
伝統文様のアレンジも、まったく新しい文様の生成も同じしくみで行えます。
