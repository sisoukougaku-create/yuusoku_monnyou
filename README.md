# Neo有職文様ジェネレーター

平安の宮廷装束を彩った有職文様を、ブラウザの中で
**アレンジ・組み合わせ（重ね）・新規生成**できるアプリです。

## 使い方

`index.html` をブラウザで開くだけで動きます（インストール不要・1ファイル完結）。
文字のフォント（Zen Old Mincho / Zen Kaku Gothic New）だけは Google Fonts から読み込みます。

| モード | できること |
| --- | --- |
| アレンジ | 14種の文様（立涌・唐花・青海波・七宝・亀甲・麻の葉・唐草・菊・梅・桜・流水・市松・矢絣・鶴）を、大きさ・回転・花びらの数・並び方・色・描き方で変える |
| 組み合わせ | 2つの文様を、濃さと重ね方（乗算・スクリーンなど）を指定して重ねる。おすすめの組み合わせもあり |
| 新規生成 | 「種（シード）」から文様・配色・重ね方をランダムに決める。同じ種なら同じ文様を再現できる |

- 配色：襲の色目をヒントにした9種＋個別の色変更
- 書き出し：全体PNG（1600×1600）、タイルPNG（960×960）、タイルSVG（480×480）。タイルは上下左右がつながるシームレス仕様
- グッズプレビュー：風呂敷・トートバッグ・扇子
- 保存と復元：図柄に名前を付けてページ内に保存（ページを閉じると消えます）。「設定コード」（`NY1:` で始まる文字列）を控えておけば、あとで貼り付けて名前ごと復元できます
